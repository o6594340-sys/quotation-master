# Quotation Generator for Agencies

Проект по автоматической сборке смет из нескольких прайсов DMC для MICE-агентств.

## Что улучшено в текущем MVP

- добавлен выбор языка итоговой сметы: английский или качественный русский
- интерфейс показывает выбранный режим и передаёт его в backend
- API теперь корректно обрабатывает ошибки и возвращает статус задачи

## Содержание

- [architecture.md](architecture.md) — техническая архитектура системы.
- [brief_another.md](brief_another.md) — продуктовый бриф и требования.

## Запуск

1. Запустить backend:
   `python backend/app/main.py`
2. Открыть [frontend/index.html](frontend/index.html) в браузере.
3. Создать задачу и выбрать язык выходной сметы.

## Статус

Проект находится на этапе подготовки к разработке MVP.
